# earcut dimensions parameter

Specify the number of coordinates per vertex if using more than 2D coordinates (default is 2).

Intent: To support 3D or higher-dimensional vertex data in the flat array.

Source: `node_modules/earcut/README.md`

Modality: optional

> * `dimensions` is the number of coordinates per vertex in the input array (`2` by default).
