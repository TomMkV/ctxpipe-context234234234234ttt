# qs.parse throwOnLimitExceeded

Set 'throwOnLimitExceeded' to true to generate an Error when parameterLimit or arrayLimit is reached.

Intent: To strictly enforce input constraints by failing fast instead of silently truncating data.

Source: `node_modules/qs/README.md`

Modality: optional

> If you want an error to be thrown whenever the a limit is exceeded (eg, parameterLimit, arrayLimit), set the throwOnLimitExceeded option to true.
