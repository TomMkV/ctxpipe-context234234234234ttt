# LAB Space for Color Mixing

Use the 'mix' plugin to perform color mixing via LAB color space for better visual results.

Intent: To achieve more perceptually accurate color mixing compared to standard RGB mixing.

Source: `node_modules/@pixi/colord/README.md`

Modality: recommended

> In contrast to other libraries that perform RGB values mixing, Colord mixes colors through [LAB color space](https://en.wikipedia.org/wiki/CIELAB_color_space). This approach produces better results
