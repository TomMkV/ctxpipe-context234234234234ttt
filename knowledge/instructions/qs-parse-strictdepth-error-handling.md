# qs.parse strictDepth error handling

Enable 'strictDepth' to throw a RangeError when the input exceeds the configured nesting depth.

Intent: To provide explicit error handling for deeply nested malicious or malformed input.

Source: `node_modules/qs/README.md`

Modality: optional

> You can configure qs to throw an error when parsing nested input beyond this depth using the strictDepth option (defaulted to false)
