# Prefer Responsive Design

Use responsive design and mobile-first approaches for screen size rendering instead of JS-based detection whenever possible.

Intent: To avoid unnecessary JavaScript execution and blocking for UI layout adjustments.

Source: `node_modules/ismobilejs/README.md`

Modality: recommended

> In most cases, responsive design solves the problem of controlling how to render things across different screen sizes. I recommend a mobile first approach.
