# Bundle for UMD

When using the UMD format, a bundle name must be provided via the --name flag.

Intent: To support both browser and Node.js environments with a named global variable.

Source: `node_modules/rollup/README.md`

Modality: required

> rollup main.js --format umd --name "myBundle" --file bundle.js
