# Manual Plugin Registration

Use extensions.add to register plugins like TickerPlugin when using individual @pixi packages instead of the main bundles.

Intent: To enable additional features (like tickers) when using a modular PixiJS setup.

Source: `node_modules/@pixi/app/README.md`

Modality: required

> Use extensions.add to use these plugins. _Note: if you are using pixi.js or pixi.js-legacy bundles, this is unnecessary since plugins are installed automatically by default._
