# Steiner points support

Pass a single vertex as a hole to treat it as a Steiner point.

Intent: To include specific internal points in the triangulation without creating a full hole.

Source: `node_modules/earcut/README.md`

Modality: optional

> If you pass a single vertex as a hole, Earcut treats it as a Steiner point.
