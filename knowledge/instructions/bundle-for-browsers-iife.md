# Bundle for Browsers (IIFE)

Use the IIFE format and provide a bundle name when compiling for browser <script> tags.

Intent: To create a self-executing function suitable for direct browser inclusion.

Source: `node_modules/rollup/README.md`

Modality: required

> rollup main.js --format iife --name "myBundle" --file bundle.js
